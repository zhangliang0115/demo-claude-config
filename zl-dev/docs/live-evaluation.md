## 基于观察的修正

0.11.1 收录并审核了本次会话产生的标题修复和两项回归测试。新增路径约束：插件目录仅提供工具，业务源码以真实工作目录为准；禁止没有服务证据的 localhost 地址。验收/发布已有检查项时将固定阶段模板直接放进主内容区，不再藏在详情中。

标题改动通过测试。验收主区域调整使用本次真实 task.json 重新渲染并在浏览器核对。路径与链接的提示词约束尚未另跑第二次模型会话，不能宣称已经根除该类错误。原始会话报告保留在本地运行目录 original-report.html，后续渲染检查与原会话产出分开。
