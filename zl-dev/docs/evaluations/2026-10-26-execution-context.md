# 执行上下文与协作登记评测 · 2026-10-26

## 本轮范围

新增本机 checkout 观察和协作活动登记。task.project_path、任务目录、会话焦点及原证据绑定均保持原样。登记是遵循协议的 Agent 间协调方式，不拦截任意编辑器、不自动创建 worktree、不启动/停止项目、不授予业务操作或发布权限。跨机器项目身份、任务迁移、强制接管尚未实现。

控制器创建一个含四行以内业务函数的隔离 Git 仓库和第二个 detached worktree，两份 feature 任务明确绑定主目录。实际未运行业务函数、测试服务、数据库或网络接口。该场景是合成夹具，不代表真实用户反馈；只有桌面网页检查。

## 实际 Claude Code 与控制器分工

本机真实 Claude Code 使用当前用户模型配置，通过 --plugin-dir 加载本轮插件；未覆盖模型。控制器先为 task-a 登记 write，Claude 接到 task-b 的明确范围，inspect/status 后尝试 begin。CLI 会话 success、7 个原始 num_turns、permission_denials 为空：返回 conflict，Claude 明确指出退出码 0 不等于 active，未改源码、未清理别人活动、未生成 HTML 或执行业务测试。

控制器结束自己从未执行业务命令的活动后，第一次 resume 返回 success、8 个 num_turns，但登记闭环未完成：开发期间新增 task_kind 等严格字段，使早期夹具留下的未发布历史被新版判为未知。Claude 未覆盖索引、未把 active=[] 当作可靠无活动。但它多试了两次无效 begin（先缺 revision，再把 unknown 的 null 当 missing），均被拒绝，属于不必要调用；指南已强调 unknown 不映射 missing、不重试绕过。不能把这一轮算登记成功。

原始记录与失败结果保留。控制器随后仅归档自己精确 token 对应的已停止旧格式夹具历史，没有移除其他会话记录；这是开发测试清理，不是插件的自动修复或迁移功能。最终复跑返回 success、8 个原始 num_turns、permission_denials 为空，真实 Claude 完成 begin write → status → 以自己的 token end → status，索引 observed 且无本轮遗留。控制器独立核对历史确有本会话已结束 token、两个 checkout 不同而 family 相同，业务源码 SHA 保持不变。原始回执见用户目录归档，不覆盖前一次失败记录。

最终模型答复仍有措辞风险：把活动索引 revision 未变解释成“观察期间没有实际变更”，并把无已登记写活动简写成“无写活动”。索引不能证明源码或外部状态稳定；已在 CLI 固定提示与协议中进一步写明该区别。真实模型输出不等于插件的强制保证，不把这类表述当有效业务证据。

## 独立审查发现与修复

- 幂等 read 重试提前返回，漏掉后来加入的 write 警告：改为完成全部活动比较再复用原活动。
- begin 锁等待期间任务变为 analysis：锁内重新核对 task_kind，不允许登记 write/verify。
- 截断或内部矛盾的 checkout 观察被当成有效：校验固定结构、任务身份、路径与派生哈希；损坏时 unknown，begin 拒绝而不覆盖。
- 已结束历史路径后来改为符号链接，使全局历史被判损坏：存储快照仅验证绝对、词法规范路径；当前 inspect 才解析实际路径，不按新目标改绑旧身份。

回归覆盖 Git 子目录、worktree 本机关系、non-Git 父子范围重叠、显式共享资源、只读并行、两个真实进程同 revision 竞争、CAS、owner/token、遗留不超时释放、损坏索引、Git 环境覆盖、unborn/detached 与任务类型变化。

## 展示与边界

报告页脚默认折叠“代码位置与版本”，仅展示绑定路径与代码/行为指纹；不是 Git 提交 ID，也不是运行证明。控制器为展示测试单独生成一次报告，真实 Claude 的登记测试没有生成报告。桌面浏览器验证折叠/展开与无外部资源请求；临时活动状态不写入任务评估版本，状态变化不要求重生 HTML。

登记无记录不表示没有外部写入；read 结果可在写入期间变化。活动期间不移动/重建目录，身份变化先核对，不宣称目录迁移仍受旧登记保护。无可靠 session ID 不伪造 owner：可按明确任务/已有授权的单执行者路径继续，但应说明未登记，已知冲突仍先解决。旧九类任务和 analysis 的证据流程继续保持，不把本地 Git 家族当成跨机器身份。

## 最终验证

全量 299 项回归通过（60.678s），包含 29 项活动登记与 3 项位置展示回归。最后仅补充 CLI 版本范围错误提示和固定边界文案，安装版再运行活动/展示定向检查。marketplace/plugin manifest 校验通过；目录上架检查仍提示既有 LICENSE 缺失与无 icon，不等于官方目录认证。
