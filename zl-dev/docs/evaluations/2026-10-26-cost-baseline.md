# 回放式成本初始基线 · 2026-10-26

本轮完成采样工具与第一批三对单样本，ZL-11 标记部分完成。它不是 0.16.0 发布当时的历史账单，而是把固定旧提交 a329f16 与当前提交 b53d4a2 在本机当前环境重跑。没有统计重复，不能宣称统一节省比例或完整成本归因。

## 方法与目标核对

控制器从本地 Git archive 提取 0.16.0 / 0.20.0 私有插件副本；六份独立项目、任务和全新 session。共同类型使用 feature，避开旧版不支持的 analysis/会话工具。先用各版本 CLI 建相同业务语义与已有 HTML，初始化成本与命令单列，不计入下面模型调用。顺序为进度旧/新、说明新/旧、报告旧/新，没有 resume、补跑或挑选成功结果。

每次请求 max-turns=12、进程 timeout=150 秒；它不是 token/金额硬预算，旧版进度样本实际报告 13 个 num_turns，按原值保留。六次真实 Claude Code 均返回 success；目标检查均满足，任务除指定 summary 外其他字段保持，源码未变。当前版说明更新后报告 stale 是预期延后生成，不算失败。

实际 init 验证恰好一个内联 zl-dev 路径与版本；模型为用户现有 opendesign/deepseek-v4.1-flash[1m]，Claude Code 2.1.310，未覆盖设置。归一后工具、非目标插件名/版本、权限模式及 MCP 元数据一致；仍加载 23 个工具、7 个其他插件和 2 个 MCP，不能将全部启动成本归给 zl-dev。memory_paths 原始哈希不同，因为每个新项目的自动记忆路径不同；未逐字节冻结全部全局上下文，不称纯插件隔离。

第一批开始时 sampler 只记录 logic.py 的前后文件状态及插件路径；批后独立补查所有项目 Git HEAD/status 与私有插件文件完整性、唯一插件版本，全部与准备基线一致。观察文件明确标 observed_after_batch，不伪装成各调用结束瞬间的记录。随后 sampler 增加每项 Git/插件完整性与唯一版本观察，未因此重跑模型。

## 文件与工具负载

- 进度查询：两版任务和 HTML 均未改动。Read 实际返回旧版 15,467 字节、当前版 24,685 字节，说明少调用不等于少读材料。
- 补充说明：仅 summary 改变。旧版同时重写 HTML；当前版不写 HTML，正确保留为 stale。旧版可见 Write 请求含 2,884 字节完整 task JSON；当前版没有 Write 工具请求，而用 Bash 小脚本读原 JSON、只修改 summary 后写临时完整 JSON，再 CAS update。Write=0 不能解释成没有 JSON 读写或传输。
- 索要已有报告：旧版 HTML 的 payload 只改变 generated_at；当前版字节和 mtime 均保持。两份报告均 current。
- 六份流式轨迹均有 init/result 与配对回执，解析 complete；complete 仅指轨迹完整，不代替目标检查。复杂 shell/重定向保守标 ambiguous，因此可自动确认的 render 语法计数只是下界；实际文件变化独立记录，不冒称知道所有磁盘写入次数。

每份 metrics 分开保留普通/缓存/输出、模型会话口径、Read 片段、Write 请求、Bash 参数、tool_result 文本和未知量。result.usage 不与逐消息 usage、modelUsage 或 model_usage_since_last_result 再相加；后两项和 total_cost_usd 在旧 resume 轨迹中有累计现象，本批全新 session 避免该混杂但不抹掉口径说明。

## 下一步判断

目前更有依据的是继续减少重复查询和不适用材料加载，保留版本与安全核对。不能因为全量 JSON 看起来长就直接启动通用增量更新引擎：本批当前版已能通过小脚本避免逐字复述整份 JSON，尚未证明 JSON 往返是主要模型成本。ZL-12 保持未开始。

持续会话、更多业务规模、更多模型和统计重复仍未覆盖；完整读写/网络归因也未知。ZL-11 保持“采样工具与初始基线已完成，归因与重复样本待补”，不为勾完路线图扩大采样或无休止消耗模型。

原始 prepare、事件流、stderr、outcomes、metrics-final、post-batch-integrity 与 comparison.json 保存于用户私有目录 `~/.claude/zl-dev/evaluations/2026-10-26-cost-baseline/`，不提交原文或业务日志到仓库。分析器不写任务或报告；采样器只在新建私有夹具中准备和运行指定场景，不触碰用户已有项目。fake CLI 单元测试不冒充真实会话。
