# 按需报告修复（0.16.1）

本轮仅解除强制生成 HTML，不实现会话绑定、报告并发发布保护或新的分析流程。

## 行为

- go 的新建/恢复路径使用内部 `init/continue --no-render`，不为普通解释、追问或进度建立空任务。
- 重要决定、真实执行与证据继续及时保存；本轮无需 HTML 不意味着工作未完成。
- 内部动作结束和阶段结束不自动要求 render/index；跨项目总览也按需生成。
- 复杂审阅材料、正式交接或用户明确要求页面时，按需生成或复用当前有效页面。缺失/过期如实说明，不能伪造链接。
- 旧的无标志 init/continue 保留原有行为，显式 render 保留；不增加用户命令。

## 验证

- 新增 7 项 CLI 行为回归：不生成初版 HTML、已有报告内容和修改时间保持、旧报告返回 stale、显式渲染、多候选、不带标志兼容，以及标志误用写入前拒绝。
- 全量 194 项通过（35.168 秒），独立审查的 7 项针对测试通过。
- marketplace 与 plugin 的 `claude plugin validate --strict` 均通过；这不是官方目录上架认证。
- 独立审查发现跨项目子任务初始化漏加参数、运维正文强制展示两处残留，已修正。
- 一次真实 Claude Code CLI 概念问答采用当前插件目录加载，使用用户原配置的 opendesign/deepseek-v4.1-flash[1m]，2 轮成功、无权限拒绝，结果仅文字。该用例明确要求不创建记录和 HTML，且工具仅开放 Read，不能据此证明所有默认自然语言场景或写入权限下的模型行为。
